# hack-b884deee-qarqyn
**Hackathon team repository for Qarqyn
Track 2. -- Computer Vision:
Team members(individual): Abylay Abdylmanap**

This model finds defects in imaginary case where conveyer paints a square part to red color. Minimum accepted coverage is 50% -- less the model flags it as "defected". After the painting process square parts would be taken picture which would run through this model and results would transfer to the screen which glows green and says "APPROVED", when 50& threshold is reached, or glows red and says "DEFECT: remove part", when it's less than threshold.
